# BATTLE CARDS RPG ⚔️🃏

Jogo de cartas RPG feito em **HTML, CSS e JavaScript**, com batalhas contra bots, cartas de ataque, defesa e habilidades especiais.

## Como jogar

1. Abra o arquivo `index.html` em um navegador (Chrome, Edge ou Firefox).
2. No menu principal, clique em **Jogar**.
3. Use cartas válidas para realizar ataques, defender-se e usar poderes.
4. Acompanhe a vida e os turnos durante a partida.

## Recursos

- Jogo local no navegador, sem precisar de servidor
- Cartas com efeitos RPG
- Menu, tutorial, regras e configurações
- Ranking e progressão local (salvos no navegador, conforme disponibilidade)
- Tela de carregamento com porcentagem dinâmica

## Executar pelo GitHub Pages

Se você ativar o **GitHub Pages** em **Settings → Pages**, escolhendo **Deploy from a branch → main → / (root)**, o GitHub poderá publicar este jogo como um site.

**Observação:** esta versão é de jogo local contra bots. O modo multiplayer online não está incluído. Algumas funções devem ser testadas no navegador.
